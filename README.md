#  Find Your Spark ✨

A modern and elegant Quote Generator web application built using HTML, CSS, and JavaScript.

This project fetches inspirational quotes from a public API and presents them with a polished user interface and smooth user experience.

## ⚙️ How It Works

The application fetches quotes from:

```bash
https://api.freeapi.app/api/v1/public/quotes
```

Features include:

- Generating a random quote instantly
- Displaying a deterministic "Quote of the Day"
- Rendering top quotes dynamically
- Error handling for failed API requests
